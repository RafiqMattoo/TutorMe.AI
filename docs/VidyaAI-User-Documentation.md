# Welcome

VidyaAI is an enterprise-grade, NEP 2020-aligned School Management System for Indian schools.

It unites a school's daily work in one secure, multi-school platform:

- Student records & admissions
- Academic structure & grading
- Transport
- AI-assisted teaching content
- Parent communication

**Who this guide is for:** Super Administrators, School Administrators, Teachers, Students, and Parents.

\newpage

# Key Benefits

- **One platform** — admissions, academics, transport, and content in a single place.
- **NEP 2020-ready** — stages, streams, co-scholastic subjects, and the Holistic Progress Card model.
- **AI-assisted teaching** — turn any PDF into flashcards, quizzes, lesson plans, and narrated lessons.
- **Multi-school** — each school's data stays private under one platform.
- **Compliance-aware** — APAAR, RTE, CWSN, and category fields built in.
- **Audit-friendly** — soft deletes retain history.

# Quick Start — School Administrator

1. Sign in and open the **Dashboard**.
2. Go to **Academics** → add classes, sections, subjects.
3. Set **Grading Scales** and the current **Academic Year**.
4. Add staff and students under **Users**.
5. Approve pending members under **Approvals**.
6. Set up **Transport** (optional).

> **Tip:** Build Academics first — student placement needs classes and sections.

\newpage

# Quick Start — Teacher

1. Open **Materials** → upload a PDF; wait for **Ready**.
2. Generate **Flashcards**, a **Quiz**, or a **Lesson Plan**.
3. Optionally write an **Article** or a **Narration**.
4. Create a **Delivery** and schedule it for a date.
5. Students see it under **Today**.

> **Tip:** Clear, text-based PDFs give the best AI results.

\newpage

# Quick Start — Student & Parent

1. Sign in and open **Today** for the day's tasks.
2. **Read** the material — or **listen** with Recite / Explain.
3. **Practise** with quizzes and flashcards.
4. Ask the **AI Tutor** about anything you read.
5. Browse **Articles** for extra learning.

> **Tip:** Stuck on a topic? Ask the Tutor — it answers from your material.

# Getting Started: Sign-in & Registration

*Used by: Everyone*

**Sign in**

- Enter email and password on the **Login** page.
- Sessions renew automatically.
- Pending / rejected / disabled accounts get a clear message.

**Register a school**

1. Fill the **Register** form (school + first admin).
2. Created as **Pending**.
3. Super Administrator reviews under **Approvals**.
4. Approved → school active, trial begins, admin notified.

**Register as teacher / student**

- Self-register and pick a school → **Pending** until the School Admin approves.
- Password needs one uppercase letter and one digit.
- Admin-created accounts are auto-approved.

# Approvals Workflow

*Used by: Super Administrator (schools) · School Administrator (members)*

Nothing self-registered goes live until reviewed here.

**Pending schools — Super Administrator**

- **Approve** — activates school, admin, enrollments; starts 14-day trial; notifies admin.
- **Reject** — rejects school & admin; suspends enrollments; notifies admin.

**Pending members — School Administrator**

- **Approve** — activates account; notifies user.
- **Reject** — deactivates account; notifies user.
- School Admin sees only their own school; Super Admin sees all.

> **Tip:** Check Approvals daily so new staff and students aren't left waiting.

# Academic Structure

*Used by: School Administrator · Teacher · NEP 2020-aligned*

- **Classes** — grades 0–12+, NEP stage, promotion level.
- **Sections** — divisions (5-A, 5-B), class teacher, capacity, stream.
- **Subjects** — code, medium; flag as language or co-scholastic.
- **Subject–Teacher Allocations** — subject ↔ class/section ↔ teacher.
- **Streams** — Science / Commerce / Humanities at Secondary.
- **Houses** — name, house master, colour.
- **Grading Scales** — board scales, grade bands, default.
- **Academic Years & Terms** — session dates, current year, nested terms.

# Setting Up a New Session

*Used by: School Administrator*

A recommended order for starting a new academic year:

1. Create the **Academic Year** (e.g. 2025–26) and mark it current.
2. Add **Terms** / semesters in order.
3. Create or roll over **Classes** and **Sections**.
4. Define **Subjects** and link **Streams** where needed.
5. Make **Subject–Teacher Allocations**.
6. Confirm the **Grading Scale** and default.
7. Place students (admissions / promotion).

> **Tip:** Exactly one academic year can be "current" at a time.

# Student Information System (SIS)

*Used by: School Administrator & Teacher (view) · School Administrator (edit)*

The master register of every student.

**Find students**

- Search by name, admission no., or roll no.
- Filter by class, section, status.

**Add / edit a student**

- **Identity** — name, gender, DOB, admission/roll no., photo.
- **Placement** — year, class, section, house.
- **Contact** — email, phone, address.
- **Compliance** — category, CWSN, RTE, Aadhaar / APAAR.
- **Guardians** — father/mother/guardian details.
- **Account** — optional Student/Parent login link.

> **Life cycle:** Active → Graduated / Transferred-Out → Alumni / Inactive.

# Transport Management

*Used by: School Administrator*

- **Vehicles** — registration, model, capacity, driver; activate/deactivate.
- **Routes** — name, code, vehicle, fare, frequency; stop & student counts.
- **Stops** — ordered stops, pickup/drop times, optional fare.
- **Allocation** — assign students to route & stop; capture fare; toggle active.

**Set up transport**

1. Add **Vehicles** with capacity and driver details.
2. Create **Routes** and assign a vehicle and fare.
3. Add **Stops** in order with pickup/drop times.
4. **Allocate** students to a stop on a route.

# Materials (PDF Library)

*Upload: Super Admin · School Admin · Teacher | Read: Everyone*

- Upload a PDF; it indexes in the background.
- Status: **Processing → Ready** (or **Failed**).
- Metadata: title, file name, size, page count, category.
- Once **Ready**, it powers the Tutor, flashcards, quizzes, and lesson plans.

> **Tip:** If a material shows **Failed**, re-upload a clearer, text-based PDF.

# AI Study Tools

*Generate: Super Admin · School Admin · Teacher | Use: Everyone*

Built from any **Ready** material in a few clicks.

**Flashcards**

- 3–30 cards: question on front, answer on back.
- Study mode to flip and review.

**Quizzes**

- 3–25 multiple-choice questions; Easy / Medium / Hard.
- Four options + explanation each.
- Attempts record score and answers.

**Lesson Plans**

- From a material + subject, grade, duration (15–240 min).
- Structured: objectives, activities, assessment.

# Data Privacy & Compliance

*Built into VidyaAI*

- **APAAR ID** — one-nation-one-student lifelong identifier.
- **RTE** — flags 25% EWS-quota eligibility.
- **CWSN** — records special-needs status and nature.
- **Category** — General / SC / ST / OBC for reporting.
- **Soft deletes** — records are retained for audit, not erased.
- **School isolation** — one school never sees another's data.

> Always handle student data per your school's policy and applicable law.

# Glossary

- **NEP 2020** — National Education Policy; VidyaAI's academic model follows it.
- **APAAR** — One-nation-one-student lifelong ID.
- **RTE** — Right to Education; 25% EWS quota flag.
- **CWSN** — Children With Special Needs.
- **Co-scholastic** — Arts, sports, life-skills for the Holistic Progress Card.
- **Stream** — Science / Commerce / Humanities track.
- **Material** — An uploaded PDF that powers AI tools.
- **Delivery** — A dated learning task (material + quiz + flashcards).
- **Enrollment** — A user's membership of a school with a role.
- **Soft delete** — Hidden but retained for audit.

# Frequently Asked Questions

**I registered but can't sign in.**
Your account is **Pending**. A school registers → Super Admin approves; a teacher/student → School Admin approves.

**Why is my material "Processing"?**
PDFs index in the background. Wait for **Ready** before generating tools.

**Can one person belong to two schools?**
Yes — via multiple **Enrollments**, with one marked primary.

**Who can create AI quizzes and flashcards?**
Teachers, School Admins, and Super Admins. Everyone can use them.

**Is deleted data really gone?**
No — most deletes are **soft deletes**, kept for audit.

# Troubleshooting

| Problem | Likely cause | Fix |
|---------|--------------|-----|
| Can't sign in | Account pending/rejected | Wait for approval; check the on-screen message |
| Material stuck Processing | Large or image-only PDF | Wait, then re-upload a text-based PDF |
| Material Failed | Unreadable file | Re-upload a clearer PDF |
| No deliveries on Today | None scheduled for today | Ask a teacher; check the date |
| Can't see a menu item | Role restriction | See the Access Matrix |
| AI tool won't generate | Material not Ready | Wait for Ready status |

# Tips & Best Practices

- Build **Academics** before adding students — placement needs classes/sections.
- Upload clear, text-based PDFs for the best AI results.
- Use **categories** and **tags** so content stays findable.
- Schedule **deliveries** ahead so **Today** is always populated.
- Review **Approvals** regularly so no one is left waiting.
- Mark one **Enrollment** primary for multi-school users.
